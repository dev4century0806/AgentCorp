# Architectural Decision Records (ADR Index)

This directory maintains Architecture Decision Records (ADRs). Each record captures:
1. **Context:** The technical problem or operational challenge encountered.
2. **Decision:** The chosen design approach and rationale.
3. **Consequences:** Positive impacts, limitations, and trade-offs.

This prevents regression or accidental deletion of core architectural patterns by explaining *why* decisions were made.
